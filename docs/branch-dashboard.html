배송 연동

Haggle에는 ShipEngine / ShipStation 개발자 배송 서비스를 기본 배송 추상화 대상으로 잡고, Shippo를 예비 후보로 두는 구성이 가장 깔끔합니다. 결제 완료 후 배송비 조회, 라벨 구매, 추적 이벤트 알림, 주문 상태 업데이트까지 서버에서 자동화하기 쉽기 때문입니다.

ShipEngine / ShipStation 개발자 배송 서비스

1순위
용도Haggle 백엔드에 직접 붙일 배송 인프라
기능배송비 조회, 라벨 구매, 주소 검증, 추적, 추적 이벤트 알림, 반품 라벨, 자체 운송사 계정 연결
가격무료 시작 구간이 있고, 고급 플랜은 월 요금과 라벨 수 기준 과금 구조입니다. 자체 운송사 계정을 쓰는 고급 사용은 유료 구간을 확인해야 합니다.
주의ShipEngine 브랜드가 ShipStation 개발자 배송 서비스로 정리되는 중이라 문서/콘솔 명칭이 섞일 수 있습니다.
판단결제 완료 후 자동 라벨/추적 생성 흐름에 가장 잘 맞습니다.

Shippo

2순위
용도빠르게 붙이는 중소형 커머스 배송
기능배송비 비교, 라벨 구매, 추적, 추적 이벤트 알림, 반품, 주소 검증, 여러 운송사 연결
가격무료/유료 플랜 기반입니다. 사용량, 운송사, 고급 기능에 따라 비용이 달라질 수 있습니다.
주의개발자 중심의 깊은 커스터마이징은 ShipEngine 쪽이 더 맞을 가능성이 큽니다.
판단초기 구현 속도와 운영 편의성이 좋습니다.

Easyship

조건부
용도국제배송과 관세/세금 표시가 중요한 판매자
기능국제 배송비 조회, 라벨 구매, 관세/세금 계산, 통관 문서, 배송 규칙, 추적, 반품
가격구독 플랜에 기능과 사용량이 묶이고, 개발자 호출량은 플랜별 포함량/초과량 확인이 필요합니다.
주의미국 내 단순 배송만 먼저 처리한다면 제품 복잡도가 커질 수 있습니다.
판단해외 판매/구매를 빠르게 열 때 강합니다.

Veeqo

운영 보조
용도마켓플레이스 주문, 재고, 배송을 한 운영 화면에서 관리
기능배송 라벨, 주문 관리, 재고 관리, Amazon/eBay/Etsy/Shopify/Walmart 같은 채널 연결
가격배송 소프트웨어는 무료로 제공되지만, 실제 라벨 비용과 사용 조건은 연결 채널/운송사 기준을 확인해야 합니다.
주의Haggle 제품 내부 결제/주문 상태 머신에 직접 붙이는 개발자 인프라로는 우선순위가 낮습니다.
판단판매자 운영 도구로는 유용합니다.

Pirate Ship

수동 운영용
용도초기 수동 운영 또는 소량 배송 라벨 구매
기능United States Postal Service와 UPS 라벨 구매, 할인 요금, 간단한 웹 기반 배송 처리
가격월 요금, 숨은 수수료, 최소 사용량이 없다고 안내합니다. 라벨 비용은 별도입니다.
주의자동화된 플랫폼 연동, 추적 이벤트 처리, 주문 상태 동기화에는 한계가 큽니다.
판단제품 자동화의 기본 축으로는 부적합합니다.
