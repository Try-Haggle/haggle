# Decide 모델 라우팅

**이 문서가 Decide가 어떤 모델을 부르는지의 변경 기준이다.**
코드와 이 문서가 어긋나면 이 문서를 먼저 고친다. 구현은 `decide-model.ts`.

프롬프트 블록은 [`decide-prompt-contract.md`](./decide-prompt-contract.md).
엔진 현황 한 줄은 [`SOT.md`](./SOT.md) §5.4 · §8. 모델 id 목록을 SOT에 다시 적지 않는다.

---

## 실제로 무엇을 부르나

구매자 한 턴, 판매자 한 턴은 **각각 자기 Decide 호출**이다. 한 대화에 모델이 하나만 있는 게 아니다.

`callLLM`은 DeepSeek 요청 body의 `model`에 이번 호출 id를 넣는다. 라우터가 Flash를 고르면 그 턴은 Flash가 답을 쓰고, Pro를 고르면 그 턴은 Pro가 답을 쓴다. 구매자 세션과 판매자 세션의 entitlement가 다르면 **같은 대화에서 양쪽이 서로 다른 모델을 부를 수 있다.**

프롬프트·BOX·클립은 모델이 바뀌어도 같다. 바뀌는 것은 호출 칸이다.

---

## 카탈로그와 정책

이분법이나 3단 사다리가 아니다.

```
카탈로그  지금 부를 수 있는 모델 id. 공급자·단가·타임아웃.
정책      이번 호출의 입력 → 카탈로그에서 모델 id 하나.
```

카탈로그에 칸을 더 넣으면 정책이 그 id를 고를 수 있다. Flash, Pro, 그다음 모델, 다른 공급자도 같은 표다. 엔진에 `cheap`/`default`/`upgraded` 같은 중간 이름을 만들지 않는다. 고른 결과는 **모델 id**다.

모델을 하나 더 넣을 때 `if (category)` 나 `if (model === "pro")` 를 엔진에 늘리지 않는다. 카탈로그에 id를 추가하고 정책을 고친다. 프롬프트 계약은 그대로다.

---

## 정책이 보는 입력

카테고리로 고르지 않는다. 구매자 `my_target`로도 고르지 않는다.

| 입력 | 쓰는 이유 | 쓰지 않는 이유 |
|------|-----------|----------------|
| 공개 호가 | 매물 금액이 실패 비용·품질 예산을 정한다 | 카테고리 이름, 용량, 태그 |
| 호가 미상 | 아이폰인데 스냅샷 필드가 빠졌다고 싼 모델로 떨어지면 안 된다 | 판매자 바닥, 구매자 목표 |
| 서버가 쓴 허용 모델 | 장부가 깎은 뒤에만, 그 세션이 쓸 수 있는 모델 id | 클라이언트 body 비트, 쿼리 플래그 |
| (나중) 역할·라운드·피크 | 같은 매물이어도 첫 턴/막 턴, 구매자/판매자를 다른 id로 부를 수 있다 | 지금은 안 씀. 표에 열을 더할 자리 |

`pro_model_credit`는 지금 구현의 **임시 boolean**이다. 지갑이 아니다. 클라이언트를 믿으면 안 된다. W2026-08-22-05가 차감한 뒤에만 서버가 켠다. 모델이 늘면 이 비트 하나가 아니라 **이 세션이 써도 되는 모델 id 목록**이 된다.

판매자 호가가 스냅샷에 없을 때만 판매자 `my_target`을 공개 호가 대용으로 본다. 구매자 목표는 대용이 아니다.

## 지금 돌아가는 표 (Phase 0)

카탈로그에 두 칸이 있다. 나중에 칸이 늘어도 이 표만 고친다.

| 모델 id | env | 언제 고르나 |
|---------|-----|-------------|
| `deepseek-v4-flash` | `DEEPSEEK_FLASH_MODEL` | 공개 호가 < $100 이고, 서버가 다른 모델을 허용하지 않았을 때 |
| `deepseek-v4-pro` | `DEEPSEEK_MODEL` | 공개 호가 ≥ $100, 호가 미상, 또는 장부가 이 id를 허용했을 때 |

임계는 `DEEPSEEK_PRO_ASK_THRESHOLD_USD`(기본 100). 카테고리 상수가 아니다.

---

## 크레딧과의 관계

크레딧은 모델 id가 아니다. 이번 세션이 어떤 모델을 불러도 되는지, 장부가 깎은 뒤에 서버가 허용 목록에 넣는 예산이다.

- 시작 게이트가 장부를 깎고, 깎인 뒤에만 세션 스냅샷에 허용 모델을 쓴다.
- 엔진은 스냅샷만 읽는다. 시작 JSON의 `pro_model_credit`는 훅일 뿐 결제가 아니다.
- 판매자 쪽을 더 비싼 모델로 쓰는 비용을 구매자 청구에 얹지 않는다. 차액은 우리 원가이거나 판매자 상품이다.

장부·지급표는 W2026-08-22-05. 이 문서는 누구에게 어떤 모델 id를 부를지만 정한다.

---

## 하지 말 것

- 카테고리·태그·용량으로 모델 고르기
- 구매자 목표가로 더 싼 모델 고르기
- 클라이언트 플래그를 결제처럼 믿기
- 라우터에 `cheap`/`default`/`upgraded` 같은 3단 이름을 다시 넣기
- 프롬프트나 Referee에 `if (model === "flash")` 품질 분기 넣기. 품질이 모자라면 스킬을 보강하고, 라우팅은 위 입력만
- 라이브 경로에서 Faratin으로 모델을 고르거나 타임아웃을 채우기
- 새 모델을 넣을 때 `decide-user-prompt.ts`에 공급자 이름을 박기

---

## 변경 절차

1. 이 문서의 카탈로그와 정책 표를 고친다.
2. env·기본 id와 `decide-model.ts`를 맞춘다.
3. `decide-model.test.ts`가 새 표를 대변하게 고친다.
4. SOT §5.4 · §8은 이 문서로 연결만 유지한다.

새 공급자를 넣어도 Decide 입력 계약은 그대로다. 모델이 바뀌는 것은 그 턴의 호출 id다.
