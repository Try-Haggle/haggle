## 원칙
- 여기 문서는 **SOT의 특정 능력을 확대한 것**입니다. SOT의 해당 섹션에서 링크로 연결합니다.

- 정말 극단적인 디테일(protobuf 전체 스펙 등)은 여기도 아니라 `docs/archive/`로.
