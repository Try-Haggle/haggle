## 정행 진행 (2026-08-23)

`W2026-08-22-02`를 진행 중으로 올렸다. 프로덕션 엔진에는 아직 넣지 않았다.

조사:
- DECIDE가 실제로 읽는 값은 Faratin 숫자가 아니다. 판매자 빌더가 답한 `seller_facts`(용량, 배터리, Find My 등)와 내 쪽 `requiredCriteria` / `preferences`, 그리고 `BOX`·`B:`·`C:`다.
- 같은 태그 패밀리면 같은 시스템 프롬프트를 주면 된다. DeepSeek는 prefix cache를 자동으로 쓴다. buyer와 seller는 prefix가 둘이다.
- 태그 레벨은 이미 있다. `iphone-15-pro` 같은 납작한 태그도 `electronics → phones → iphone` 질문을 상속한다. `W2026-08-08-10`은 담당 없이 새 트리를 다시 만들지 않는다.

초안:
- 전자제품 14개 패밀리에 협상 흐름 예시(오픈, 잘못된 비교 반박, 공표 결함 양보, 하드 게이트 HOLD).
- 비교 랩 소스와 `fewshot.md`는 `nego-lab/local-fewshot/`에 올렸다. 결과 폴더·API 키·로컬 DB는 올리지 않는다.

설계 (2026-08-24): 태그 가든이 이름을 정하고, 스펙은 매물 값, 질문 층은 정확 태그로 칸만 푼다. few-shot은 전략 대본이 아니라 민감도만. 공개 흐름 압축은 HNP compact state. [hnp-compact-state.md](../engine/hnp-compact-state.md).

프로토콜 (2026-08-24): HNP는 협상만. 발견은 UCP/A2A에 맡기고 우리는 연결만 연다. 사이트 공개는 MVP와 같이. 라이브 UCP/A2A는 `W2026-08-22-07`. 리뷰어는 회의에서 정한다. 공개 스펙 [HNP.md](../protocol/HNP.md).

구현 (2026-08-24, `W2026-08-22-06` + 엔진):
- Decide가 최근 5~6줄 창으로 앞 대화를 버리던 것을 없애고, 라운드에서 FLOW+HIST+MEMO를 다시 조립한다.
- 공개 압축은 HNP compact state. 바닥가·목표가·페르소나는 엔진에 남긴다.
- 웹 자동협상(`auto-play/next`)이 호스트 HNP 봉투를 만들어 ingress를 탄다. MCP는 `hnp_submit_offer` / `hnp_accept`만 남기고 가격-only `haggle_submit_offer`는 지웠다.
- UCP/A2A는 매핑만. 라이브 어댑터는 아직 없다.
- 판매자 수동 가격 채팅(`/sell/negotiations`)과 `NegotiationChat`을 없앴다. 매물 상세는 상태만 보여준다. 사람은 중간 개입만 하고 가격은 엔진이 정한다.

다음:
- 엔진 품질을 이어서 본다. few-shot은 로컬에서 저장공간만 다른 케이스를 잰 뒤, 되면 프로덕션 system에 넣고 인오가 `W2026-08-08-07`을 다시 잰다.
- REST `price_minor` 전용 오퍼는 아직 ingress를 건너뛴다. 이 문도 닫는다.
- 스펙 사이트 공개는 MVP와 같이. 리뷰어는 회의에서 정한다.
- 라이브 UCP/A2A는 `W2026-08-22-07`. 코어가 안정된 뒤에 시작한다.
- `W2026-08-22-03` 결제 레일, `W2026-08-08-01` physical_live DELIVERED 이후 release/분쟁은 아직 손대지 않았다.
