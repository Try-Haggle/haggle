Haggle 기술 문서

AI 협상 + 온체인 결제 프로토콜 인프라. 이 문서는 실제 저장소 코드를 감사해 현재 구현된 기능·구조·모델을 설명합니다. 설계 문서(docs/engine/*.md)의 희망사항이 아니라, 오늘 프로덕션에서 실제로 도는 것에 집중합니다.

각 feature 페이지는 독립적으로 읽을 수 있습니다. 우선 Negotiation Engine부터 작성 중입니다.

Features

🚀
Start Here — 협상 엔진 신규 팀원

이상적 목표 설계(SOT) ↔ 현재 구현(현황)을 능력 단위로 대조. 1차 소스 docs/engine/SOT.md의 렌더 뷰. 상태 모델 · 파이프라인 · 협상 수학 · 백로그.
✅
Backlog / TODO 할 일
SOT §11 백로그를 코드로 재검증한 실행 목록. 각 항목이 아직 할 일인지(코드 근거) + 중요도(🔴🟡⚪)를 표시. 12개 전부 열림.
🛡️
Trust & Reputation 예정
신뢰 점수 엔진(trust-core). 온체인 신뢰 프로필, 정산 신뢰도, 전문성 배지.
⚖️
Disputes 예정
분쟁 비용 모델 + DS 패널(dispute-core).
⏳
Adaptive Review Period 예정
적응형 리뷰 기간(arp-core).
🏷️
Tag Lifecycle 예정
태그 라이프사이클(tag-core).
🔗
Smart Contracts 예정

Principle

이 문서의 원칙

📐 코드가 진실의 원천 (Code is the source of truth)
모든 서술은 실제 코드 경로를 추적해 검증합니다. 설계 문서에만 있고 코드엔 없는 것, 정의됐지만 실행 경로에서 안 읽히는 것은 정직하게 구분해 표기합니다 — ✅ 실제 동작 · 🚧 advisory/부분 · 💀 미사용/죽음 · 🚧 조사 예정.
